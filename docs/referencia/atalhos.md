# Atalhos de teclado

Tudo no Kimball tem atalho, e os botões mostram o deles na dica. No macOS, use ++cmd++ no lugar de ++ctrl++. Dentro do app, ++f1++ › **Atalhos** mostra a lista principal.

## Geral

| Atalho | O que faz |
|---|---|
| ++ctrl+k++ | Paleta: acha tabelas, colunas e relações e roda qualquer comando |
| ++f1++ | Guia "Como usar" |
| ++ctrl+n++ / ++ctrl+o++ | Modelo em branco / abrir |
| ++ctrl+s++ / ++ctrl+shift+s++ | Salvar / salvar como |
| ++ctrl+e++ | Folha **Exportar** |
| ++ctrl+shift+e++ | Exportar o diagrama |
| ++alt+s++ | Código da seleção (outro banco, versão, dependências, DBML) |
| ++ctrl+comma++ | Configurações |
| ++ctrl+z++ | Desfazer (até 500 passos) |
| ++ctrl+shift+z++ ou ++ctrl+y++ | Refazer |
| ++esc++ | Fecha, de dentro para fora: popover, edição, folha, comparação |

## Visualização

| Atalho | O que faz |
|---|---|
| ++ctrl+1++ / ++ctrl+2++ / ++ctrl+3++ | Diagrama / Dividido / DBML |
| ++ctrl+backslash++ | Alterna entre Diagrama e Dividido |
| Arrastar a divisória, ou ++arrow-left++ ++arrow-right++ com ela em foco | Largura do editor no modo Dividido (clique duplo volta a 500 px) |
| ++ctrl++ + rolar, ++ctrl+equal++, ++ctrl+minus++ | Zoom (de 10% a 500%) |
| ++ctrl+0++ | Zoom em 100% |
| ++shift+1++ | Ajustar o diagrama à tela |
| ++shift+l++ | Organizar o diagrama |

## Canvas

| Atalho | O que faz |
|---|---|
| ++v++ | Selecionar |
| ++space++ (segurar) | Mover o canvas |
| ++t++ ou clique duplo no canvas | Nova tabela |
| ++1++ / ++2++ / ++3++ | Relação 1:1 / 1:N / N:N (arraste do pai para o filho) |
| ++shift++ + clique numa tabela, com ++1++, ++2++ ou ++3++ | Ligar a tabela a ela mesma (autorrelação) |
| ++g++ | Agrupar a tabela selecionada |
| ++n++ | Nova nota |
| ++del++ | Apagar a seleção (o aviso tem **Desfazer**) |
| Clique duplo no nome | Renomear a tabela |
| Clique duplo na coluna | Editar a coluna no lugar |

## Edição de coluna

| Atalho | O que faz |
|---|---|
| ++enter++ (tabela selecionada) | Nova coluna: digite nome e tipo, como `telefone varchar 20` |
| ++arrow-up++ ++arrow-down++ | Escolher o tipo sugerido |
| ++tab++ | Completar o tipo |
| ++enter++ | Gravar e abrir a próxima coluna |
| ++esc++ | Cancelar |

## Editor DBML

| Atalho | O que faz |
|---|---|
| ++ctrl+space++ | Completar palavras, tipos e colunas (também dentro de `Ref`) |
| ++f12++ | Ir para a definição |
| ++f2++ | Renomear em todo o arquivo |
| ++shift+alt+f++ | Formatar o arquivo |

## Assistente de IA

| Atalho | O que faz |
|---|---|
| ++ctrl+j++ | Abrir ou fechar o assistente (funciona também com o foco no editor) |
| ++ctrl+m++ | Trocar o modelo de IA, com o assistente aberto |
| `@` | Citar uma tabela na pergunta |
| ++enter++ | Enviar a pergunta |
| ++ctrl+enter++ | Aplicar a proposta |
| ++esc++ | Cancelar a resposta ou fechar o assistente |

Mais em [Assistente de IA](../assistente/index.md).

## Comparação com o banco

| Atalho | O que faz |
|---|---|
| ++j++ / ++k++ | Próxima / anterior diferença |
| ++enter++ | Incluir ou tirar o passo do script |
