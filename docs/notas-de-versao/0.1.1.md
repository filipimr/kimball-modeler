# Kimball Modeler 0.1.1

**Publicada em 25 de novembro de 2026 · Versão de correção**

Corrige três problemas da 0.1.0 e deixa MySQL e Oracle disponíveis na exportação pela interface. A atualização é recomendada para todos e não muda nada nos seus arquivos `.dbml`, `.layout.json` ou `.ai.json`.

[Baixar a 0.1.1](https://github.com/filipimr/kimball-modeler/releases/tag/v0.1.1){ .md-button .md-button--primary }

## Destaque

### Exportar DDL para MySQL e Oracle

Os dois bancos já eram suportados pelo motor do Kimball e pelo terminal (`kimball export --dialect mysql`), mas faltavam na tela. Agora aparecem em **Exportar › Script DDL › Dialeto**, cada um com suas versões:

| Banco | Versões |
| --- | --- |
| MySQL | 8.0, 8.4 e 9.0 |
| Oracle | 19c, 21c e 23ai |

A lista também passou a mostrar todas as versões de PostgreSQL (12 a 18) e SQL Server (2016 a 2025). Veja [Exportar](../guia/exportar.md).

## Novo

- **Modelo padrão do projeto**, em Configurações › Assistente › Neste projeto: escolhe qual modelo de IA responde quando você abre aquele projeto. Sem escolha, vale o último usado. Fica gravado no `<arquivo>.ai.json`. Veja [Provedores](../assistente/provedores.md).

## Correções

Exportar › Script DDL
:   A lista de bancos de destino era fixa e deixava bancos e versões de fora. Agora vem do próprio app, com tudo o que ele suporta.

Assistente › troca de modelo
:   A lista de modelos abria para baixo, ficava cortada pela borda da janela e não deixava escolher. Agora abre acima do campo de mensagem e rola quando a janela é baixa.

Configurações › Assistente › Neste projeto
:   Num modelo ainda não salvo (um modelo novo ou o exemplo Northwind), os campos ficavam desligados sem explicação clara, e parecia que a tela estava travada. Agora a seção diz o motivo e oferece **Salvar o modelo…**. Os campos mostram o que já está salvo no projeto, e a seção continua visível mesmo se a leitura falhar.

## Como atualizar

- **Instalador `.exe`:** o app avisa na próxima abertura e atualiza em um clique.
- **`.msi` ou CLI avulsa:** baixe os arquivos da [release 0.1.1](https://github.com/filipimr/kimball-modeler/releases/tag/v0.1.1) e instale por cima da versão anterior.

## Arquivos

| Arquivo | Para quê |
| --- | --- |
| `Kimball.Modeler_0.1.1_x64-setup.exe` | instalador recomendado para Windows, com atualização automática |
