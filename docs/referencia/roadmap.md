# Roadmap

O que já está no app e o que vem a seguir. Os itens planejados não têm data e podem mudar de ordem. Para pedir um recurso, [abra uma issue](https://github.com/filipimr/kimball-modeler/issues).

## Disponível

- Diagrama e DBML sincronizados, com editor que entende DBML.
- Relacionamentos 1:1, 1:N, N:N e autorrelação, com FK e índice criados sozinhos.
- Validação e DDL para PostgreSQL 12 a 18, SQL Server 2016 a 2025, Snowflake, MySQL 8.0 a 9.0 e Oracle 19c a 23ai, com correção em um clique.
- Domínios, sequences, colunas geradas, índices avançados, particionamento, roles e permissões.
- Importação de scripts SQL/DDL, planilhas e Modelo Físico XML (.pdm), e conexão com PostgreSQL.
- Comparação com o banco, presets de ambiente e execução numa transação.
- Exportação de diagramas, dicionário de dados, JSON Schema, XSD e dados de teste.
- CLI, servidor MCP com 39 ferramentas e 5 skills.
- Assistente de IA com o seu provedor, e Claude Code pela assinatura.
- Atualização automática assinada.

## Planejado

- Pacotes para Linux e macOS na página de downloads.
- Instaladores do Windows com assinatura de código.
- Login de conta pelo navegador nos provedores do assistente.
- Conexão direta com SQL Server, Snowflake, MySQL e Oracle.
- Novos bancos: BigQuery, Databricks e Redshift.
- Integração com dbt e ODCS v3.
- Camadas conceitual, lógica e física.
- Views, funções, procedures e triggers no modelo.
