# Kimball Modeler 0.1.0

**Publicada em 25 de novembro de 2026 · Primeira versão pública**

Modelador de bancos de dados para desktop, com canvas visual, editor DBML, CLI, servidor MCP e assistente de IA.

[Ver a release 0.1.0](https://github.com/filipimr/kimball-modeler/releases/tag/v0.1.0){ .md-button }

## Destaques

Canvas e editor DBML sincronizados
:   Desenhe no diagrama ou escreva DBML: os dois lados se atualizam na hora, e comentários, ordem e formatação do arquivo são preservados. As posições ficam em `<arquivo>.layout.json`, separadas, para diffs limpos no Git.

Cinco bancos, validados por versão
:   DDL e scripts `ALTER` para PostgreSQL (12 a 18), SQL Server (2016 a 2025), Snowflake, MySQL (8.0 a 9.0) e Oracle (19c a 23ai), com domínios, sequences, colunas geradas, índices avançados, particionamento, roles e permissões.

Assistente de IA (`Ctrl J`)
:   Use o seu provedor: Anthropic, OpenAI, Google Gemini, Ollama local, um servidor compatível com OpenAI ou o Claude Code pela sua assinatura. A chave fica no cofre do sistema e só a estrutura do modelo é enviada, nunca dados. Toda mudança vira proposta tracejada no canvas e só entra quando você aplica.

Comparação modelo × banco
:   Cada mudança vem classificada (direta, recriação ou sem suporte). Passos destrutivos começam desmarcados, há presets por ambiente e a execução no PostgreSQL é transacional, com SSL/TLS.

Importação e exportação
:   Importa PostgreSQL, scripts SQL/DDL, planilhas Excel/CSV e Modelo Físico XML (`.pdm`). Exporta DDL (um script, vários arquivos para migrações ou só os `DROP`), diagramas (SVG, PNG, JPG, PDF, Mermaid), dicionário de dados (HTML, RTF, Excel, CSV), JSON Schema, XSD e dados de teste.

CLI e servidor MCP
:   O programa `kimball` modela, valida e exporta pelo terminal e no CI, e liga o Kimball à IA da sua IDE com 39 ferramentas e 5 skills.

Atualização automática assinada
:   O app procura versões novas e confere a assinatura antes de instalar.
